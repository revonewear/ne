# REVONE — website starter

Responsive catalogue website for REVONE. It can be hosted free with GitHub Pages. No paid domain or always-on home computer is required.

## Before publishing
1. Replace `REPLACE_WITH_INSTAGRAM` in `index.html` with your Instagram username (without @).
2. Replace `REPLACE_WITH_TIKTOK` with your TikTok username (without @).
3. Confirm the email `revone.ver@gmail.com`.
4. Replace product placeholders with your own photos when ready.

## Add product photos
Upload photos into the `images` folder, e.g. `images/cloud-hoodie.jpg`. In `index.html`, find the product's `<div class="product-image">` and replace `<div class="placeholder-label">CLOUD<br>HOODIE</div>` with `<img src="images/cloud-hoodie.jpg" alt="Cloud Hoodie">`. Keep the `tag` element if you want the label over the photo.

## Publish with GitHub Pages
1. Create a **public** repository named `revone-website`.
2. Upload `index.html`, `README.md`, and the `images` folder.
3. Open **Settings → Pages**.
4. Under Build and deployment choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait a few minutes. GitHub will show the published URL in Settings → Pages, usually `https://YOUR-USERNAME.github.io/revone-website/`.

This is a catalogue site, not an online payment system. Update social links before publishing.
